Kartu KARTA

KARTA adalah Kartu Akses dan Rekam Terpadu Warga, identitas resmi warga untuk pelayanan terpadu desa dan posyandu.

KARTAKartu Akses dan Rekam Terpadu Warga
Portal Kartu KARTA

https://gopositif.github.io/karta/

Isi Kartu

Kartu memuat ID Akses Web (contoh GP-0001) dan QR untuk dipindai kader. PIN default diberikan terpisah kepada warga.

Kegunaan

Dipindai kader saat absen dan pemeriksaan. Warga memakai ID dan PIN untuk layanan mandiri di Web Posyandu dan Web Pelayanan Desa.

Di Aplikasi Kartu KARTA

Buat dan desain kartu baru, cari data warga untuk cetak ulang, ubah data dan anggota keluarga, lalu cetak atau ekspor PNG dan PDF.
